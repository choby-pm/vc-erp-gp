# VC ERP — GP

VC 운용사(GP)가 펀드를 기획·모집·결성·운용·보고·청산하는 전 과정을 다루는 ERP MVP.
추후 별도의 LP 시스템과 API로 연동한다. 개인 연구 목적 프로젝트이며 실제 서비스와 무관하다.

- 기획 문서: [docs/README.md](docs/README.md)
- 기술 스택: Next.js, Tailwind CSS, PostgreSQL(Neon, SQL 직접 작성), Vercel

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 연다.

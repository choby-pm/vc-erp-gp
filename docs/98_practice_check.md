# 98. 실무 확인 목록

설계하면서 ⚠️로 표시한 부분을 한곳에 모았다. 실무 경험자에게 확인한 뒤 결과를 적고, 규칙이 바뀌면 관련 문서와 코드를 함께 고친다.

- 상태: ⬜ 미확인 · ✅ 확인 완료 · ✏️ 확인 후 수정 필요
- "영향 시점"은 이 내용이 코드에 반영되어야 하는 릴리스다. 그 전에 확인하면 된다.

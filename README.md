# VC ERP — GP 운용 시스템

VC 운용사(GP)가 투자조합 하나를 **기획 → 모집 → 결성 → 운용 → 보고 → 회수·청산**까지 한 시스템에서 처리하는 ERP입니다.
돈이 움직이는 모든 기록은 **조합원 원장과 복식부기 분개장에 같은 트랜잭션으로** 남고, LP(출자자)에게는 **공개 등급으로 거른 데이터만** API로 나갑니다.

> 개인 연구 목적 프로젝트이며 실제 서비스와 무관합니다. 표시되는 조합·기업·출자자는 모두 가상 데이터입니다.

## 🔗 데모

**https://vc-erp-gp.vercel.app** → 로그인 화면의 **데모 계정으로 둘러보기**

GP · LP 두 시스템을 한 장으로 보는 소개 페이지: **https://vc-erp-lp.vercel.app/intro**

- 관리자 권한으로 모든 기능을 직접 써 볼 수 있습니다 (캐피탈콜 발송, 분배 지급, 결산 등).
- 데모 전용 DB라 **매일 새벽 3시(KST)에 원래 데모 데이터로 초기화**됩니다. 마음껏 눌러 보셔도 됩니다.
- 샘플 조합 8개가 생애주기 단계별로 들어 있습니다. 추천 순서는 [10분 데모 가이드](docs/00_summary.md#4-데모-순서-약-10분)에 있습니다.

## 무엇을 만들었나

| 영역 | 주요 기능 |
|---|---|
| 조합 기획·모집·결성 | 규약(버전 이력), 출자 제안(발송·확약·거절), 조합원 명부 확정, 결성총회, 최소 결성 기준·체크리스트 |
| 출자·원장 | 캐피탈콜(약정 비율 자동 배분·납입·미납 관리), 조합원별 원장(추가만 가능, 정정은 취소 행) |
| 투자·회수 | 딜 파이프라인(칸반), 투자 집행(투자 가능 잔액·거래일 기준 현금 초과 차단), 포트폴리오·평가, 의무투자 모니터링, 회수(처분손익) |
| 분배·성과보수 | 워터폴(원금 → 기준수익 → 초과수익·성과보수) 누적 계산, 초안 → 확정(LP 통지) → 지급, 취소 |
| 재무·회계 | 업무 기록에서 **복식부기 자동 분개**, 계정별 원장, 시산표, 재무상태표·손익계산서, 사업연도 결산·기간 잠금·재개 |
| 총회·보고 | 약정 기준 의결권 총회, 가결에 따른 상태 변경, 정기 보고(발행 시 스냅샷), 통지와 LP별 확인 현황, PDF 첨부 |
| LP 연동 | LP 시스템용 API(API 키 인증, 공개 등급 필터), HMAC 서명 웹훅(아웃박스 + 재시도 + 순서 보장), LP 직접 투표 |
| 권한·감사 | 역할 4종(관리자·운용·재무·조회, 직무 분리), 모든 쓰기·로그인·거부 시도를 남기는 감사 로그 |

규모: 테이블 37개 + 계산용 뷰, 마이그레이션 15개, GP 내부 API 94개, LP 연동 API 13개

## 설계에서 신경 쓴 것

| 원칙 | 구현 |
|---|---|
| 원장은 추가만 | 원장·분개장·감사 로그는 DB 트리거로 수정·삭제 차단. 틀리면 취소 행·역분개로 정정 |
| 계산 값은 저장하지 않음 | 약정 총액·현금·투자 가능 잔액은 뷰에서 계산 → 대시보드와 조합 화면 숫자가 항상 같다 |
| 세 겹의 방어선 | 화면 검사 → 서버 업무 규칙(오류 코드 + 규칙 ID) → DB 제약·트리거 |
| 돈이 움직이면 한 트랜잭션 | 업무 기록 + 조합원 원장 + 자동 분개 + 통지 + 연동 이벤트를 함께 저장하거나 함께 취소 |
| 동시 처리 | 조합 행 잠금, 돈이 움직이는 요청은 `Idempotency-Key` 로 중복 방지 |
| 권한 검사는 한곳에서 | API 94개를 하나씩 고치지 않고 공통 처리 한곳에서 주소 규칙표로 검사 → 새 API에도 자동 적용 |

설계 결정 44개와 그 이유는 [결정 기록](docs/99_decisions.md)에 남겼습니다. 실무 규칙을 확인하지 못해 단순화한 부분(워터폴 캐치업·세금 등)은 화면과 [실무 확인 목록](docs/98_practice_check.md)에 ⚠️로 밝혀 두었습니다.

## 기술 스택

- **Next.js 16** (App Router, Route Handlers, Server Components), TypeScript, Tailwind CSS
- **PostgreSQL** (Neon) — ORM 없이 SQL 직접 작성 (`postgres.js`), 입력 검증은 zod
- **Vercel** — 배포(싱가포르 리전), Cron(이벤트 전송·데모 초기화), Blob(비공개 파일)

## 로컬 실행

```bash
npm install
npm run db:migrate                 # .env.local 의 DATABASE_URL 에 마이그레이션
npm run db:seed && npm run db:seed-staff
npm run db:seed-sample && npm run db:seed-sample-deals && npm run db:seed-sample-exits && npm run db:seed-sample-lifecycle
npm run dev                        # http://localhost:3000
```

필요한 환경 변수는 [제출용 요약 8장](docs/00_summary.md#8-실행-방법)에 있습니다.

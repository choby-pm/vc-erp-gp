# 96. GP 단독 QA 시나리오 — 조합 생애주기 순서

> GP가 조합 하나를 기획부터 청산까지 처리하는 순서대로, GP 기능만 확인한다. **이 문서는 `scripts/qa-gp-catalog.mjs` 에서 만든다** (`npm run qa:gp-report`) — 항목을 바꾸려면 그 파일을 고친다
>
> - 실행: `npm run qa:gp -- --reset` (배포 GP 데모에 실제로 요청, 끝나면 짝 맞춘 데모 갱신으로 되돌림) → `npm run qa:gp-report` (결과지 docs/qa-reports)
> - GP ↔ LP 연동(웹훅 · 응답 API · 공고 지원 · 대사)은 LP 저장소 `docs/96_qa_scenarios.md` 에서 본다. 둘을 생애주기 순서로 합친 혼합 결과지는 LP `docs/qa-reports/<날짜>-mixed.md`
> - 표기: 구분 "차단" = 막혀야 할 것을 막는지. 결과 열은 마지막 실행 결과
